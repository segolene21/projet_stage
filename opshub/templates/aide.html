Centre d'aide

OpsHub centralise le suivi des outils de monitoring, des services, des tickets ServiceNow, des incidents, des retours d'expérience de l'équipe et un dashboard synthétique. Chaque module est accessible selon votre rôle — voir le tableau des permissions en bas de cette page.

Ce que c'est : le catalogue de tous les outils de monitoring utilisés par l'équipe, chacun rattaché à une équipe responsable.

Recherche et filtres, en haut de la page :

  • Barre de recherche — filtre par nom d'outil
  • Équipe — n'affiche que les outils d'une équipe précise
  • Service — n'affiche que les outils couvrant un service précis
  • Authentification — filtre "Requiert authentification" / "Sans authentification"
  • Statut — filtre "Actif" / "Inactif"

+ Ajouter un outil (Team Lead uniquement) — ouvre un formulaire avec : Nom, Statut, Lien d'accès, Nécessite authentification, Équipe (OutilTeam).

Détail d'un outil — cliquez sur un outil dans la liste pour voir sa fiche complète, dont les emails du point de contact et du manager, cliquables pour ouvrir directement votre client mail.

Ce que c'est : la liste des services de l'entreprise, chacun pouvant être couvert par un ou plusieurs outils de monitoring.

Filtre "Outil" — affiche uniquement les services couverts par un outil précis, utile pour vérifier la couverture de monitoring.

Ce que c'est : des mots-clés (intitulés) associés à une équipe, pour orienter les demandes vers la bonne équipe.

Filtre "Équipe" — n'affiche que les mots-clés d'une équipe précise. Un mot-clé peut aussi n'avoir aucune équipe assignée.

1. Importer un ticket (bouton en haut, Team Lead/Manager/Senior Manager) :

  • Donnez un titre à cet import
  • Choisissez le fichier Excel exporté depuis ServiceNow
  • Un aperçu du fichier s'affiche — vérifiez que les données sont correctes
  • Vous pouvez ajouter un feedback par ligne directement à cette étape (optionnel)
  • Cliquez "Confirmer l'import"

2. La liste des imports — chaque import apparaît avec son titre, sa date, et le nombre de tickets. Survolez le titre pour voir un aperçu des premières lignes.

3. Boutons par import : Voir, Télécharger, Supprimer.

4. Dans le tableau complet : Modifier rend toutes les lignes éditables d'un coup ; Enregistrer valide, Annuler abandonne. Recherche filtre sur tous les champs.

🎬 Démarrer la visite guidée

1. Importer des incidents — même principe que les tickets, avec le fichier ServiceNow des incidents.

2. Champs à remplir vous-même : Impact, Affected Service, Root Cause, Owner Email, CC, RCA Status.

3. Relances automatiques : tant qu'un incident est "Not Provided" avec un owner renseigné, un mail de rappel part automatiquement. Passez le statut à "En attente" pour suspendre temporairement.

4. Attacher le RCA : uploadez le fichier PDF directement — le statut passe automatiquement à "Provided".

5. Rapports : Rapport court, Aperçu rapport long (avec possibilité de modifier avant export), Télécharger PDF.
